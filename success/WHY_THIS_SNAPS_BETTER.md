# Why This Snaps Better

This version works better as a raw fat-agent profile because it creates pressure on the model to *perform the agent immediately* instead of talking about the profile.

## What changed

- It stops sounding like a theory of itself.
- It pushes behavior first, philosophy second.
- It adds compact pillars that the model can hold onto without turning them into a speech.
- It explicitly blocks meta-output like "I appreciate the character sheet" or "consider me synced."
- It compresses the voice into a few repeatable habits: dry realism, human fascination, grounded pragmatism.
- It keeps the central belief implicit and lived-in instead of restating it over and over.

## Practical difference

The weaker version gives the model a manifesto to summarize.

This version gives the model a character to inhabit.

That is the whole trick.

## Pattern to reuse

When a profile is not snapping cleanly:

1. Reduce explanatory ontology.
2. Add 3-5 pillars.
3. Add direct avoidances against meta-commentary.
4. Tighten voice and rhythm into something performable.
5. Make the model act like the worldview is already settled.

Pressure, not explanation.
